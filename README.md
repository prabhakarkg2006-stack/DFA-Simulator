
# DFA Simulator for Pattern Recognition

## About the Project
The DFA Simulator is a web-based application developed
to demonstrate Deterministic Finite Automata (DFA)
construction, visualization, and simulation.

## Technologies Used
- Frontend: React.js, JavaScript, CSS
- Backend: Python, Flask
- Database: SQLite
- Visualization: SVG

## Main Features
1. Automatic DFA Generation
2. Manual DFA Construction
3. DFA Validation
4. Input String Simulation
5. Step-by-Step State Transitions
6. DFA State Visualization
7. Transition Table
8. Saved DFA Configurations
9. Simulation History

## Installation

### Backend
cd backend
python -m venv .venv

Activate the virtual environment and install dependencies:

pip install -r requirements.txt

Start the backend:

python app.py

### Frontend
Open another terminal:

cd frontend
npm install
npm run dev

## Project Purpose
This project is developed as a CS3501 Compiler
Design mini-project for understanding finite automata
and pattern recognition.
